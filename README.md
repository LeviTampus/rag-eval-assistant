# RAG Eval Assistant

A **retrieval-augmented generation (RAG) assistant with an evaluation suite**.
Ask questions about a set of documents; get answers grounded in them, with
citations — plus a suite that scores how well it does.

> **Personal learning / portfolio project.** Built to practise retrieval,
> evaluation, and observability for AI workloads. See `PROJECT.md` for the
> design and `PLAN.md` for the build plan.

Setup, usage, and evaluation results will be added as the project is built.
